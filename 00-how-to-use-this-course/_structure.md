# 00 — How to Use This Course · _structure.md

**Identity:** the reader's onboarding + operating manual for Substrate. Not a content
chapter — it is the map, the contract, and the learning method. Shortest unit in the course.

**Bespoke shape — "orientation pamphlet," not a teaching arc.** This unit has no mechanism
to explain, so it does NOT use theory→intuition→diagram→tradeoffs. It is a short, scannable
set of orientation sections a reader passes through ONCE and then refers back to. Think
airport terminal map, not a lecture.

## Dependency position
- **Depends on:** nothing (entry point).
- **Feeds into:** every other unit (sets reading conventions, the two-tier model, the
  agent-paired method, how cross-links/labs work).
- **Appendix links:** explains that appendices A–O exist and how to descend into them.

## Sections (each ~½–1 screen; this is a short unit)
1. **What this is & who it's for** — the mission (one resource, zero hand-waving), the
   persona (capable junior → senior), and an honest "what you need to know first" (can
   read code, willing to build).
2. **The two-tier map: spine vs appendices** — spine (00–34) teaches transferable CONCEPTS
   + build labs; appendices (A–O) go infinitely deep on ONE real system, reference-only.
   Show the Part 0 / I / II / III shape and where the two headlines (System Design,
   Agentic System Design) live.
3. **How to read a chapter** — the default arc (intuitive model THEN deep mechanism),
   why every claim is cited, what a `<!-- IMAGE PROMPT -->` means, how cross-links down
   into appendices work, and how build labs pair with spine chapters.
4. **The agent-paired learning method** — the distinctive bit: copy-paste prompts a reader
   gives their OWN coding agent to (a) quiz them, (b) extend a build lab, (c) explain a
   diagram, (d) check their mental model. 3–4 concrete reusable prompt templates.
5. **Three reading paths** — (a) cover-to-cover; (b) "I just need System Design" (00→
   06→11→13–21); (c) "I just need Agentic" (00→22–34, dip into M). A tiny path table.
6. **Conventions & contributing** — citation style, `[UNVERIFIED]` meaning, the /build
   directory, how to file issues / contribute (public, contribution-friendly).
