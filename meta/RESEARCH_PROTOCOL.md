
# Research protocol

Goal: a corpus so complete that drafting requires no further searching.

Per sub-course:
1. Brain lists the source clusters from RESEARCH_INDEX.md for this sub-course.
2. Fan out one `researcher` per cluster, in parallel.
3. Each researcher returns, into <subcourse>/_research.md, a structured brief:
   - Key mechanisms (how the thing actually works, deeply).
   - Foundational sources (paper / source file / canonical doc) with links.
   - The "why it's this way" constraints (the forcing functions).
   - Common misconceptions to preempt.
   - Best build-your-own target(s) for this material, if any.
   - Open questions / where sources disagree.
4. Brain reconciles overlaps, flags gaps, and expands RESEARCH_INDEX.md with new finds.
5. factchecker spot-checks the most load-bearing claims before the corpus is accepted.

Rules: primary sources first; record the exact link per claim; never let a researcher
write course prose — briefs only.
